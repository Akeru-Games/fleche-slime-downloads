# Flèche & Slime — bêta Android v129

[Télécharger la version actuelle pour Android](https://github.com/Akeru-Games/fleche-slime-downloads/releases/download/v0.129-beta/Fleche-Slime-Android-v129.apk)

Installer ce fichier par-dessus le jeu existant, **sans désinstaller le jeu**, afin de conserver les données locales. Une ancienne bêta sans lecteur de mise à jour nécessite ce téléchargement complet une fois.

La v129 vérifie les nouvelles versions au lancement. Lorsqu’un petit patch compatible existe, il se télécharge automatiquement en Wi-Fi, le jeu le prépare puis ouvre directement l’installateur Android. Le joueur confirme l’installation. Il n’a pas besoin de chercher un fichier dans les dossiers du téléphone.

[Voir la page de la version actuelle](https://github.com/Akeru-Games/fleche-slime-downloads/releases/tag/v0.129-beta)

Les fichiers `.fsdelta` de cette page sont utilisés par le jeu ; ils ne doivent pas être installés manuellement. Les anciennes versions peuvent encore avoir leur ancien parcours jusqu’à cette transition. En l’absence de petit patch compatible, un téléchargement complet reste à confirmer.

Bêta distribuée par Akeru. Achats réels désactivés. Android uniquement pour ce lien.
