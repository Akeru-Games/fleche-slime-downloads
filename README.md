# Flèche & Slime — bêta Android v131

## Vous avez déjà la v129 ou la v130 ?

Gardez le Wi-Fi, fermez complètement le jeu puis relancez-le. La mise à jour intégrée télécharge le patch adapté : **environ 94 Mo depuis la v129 ou 87 Mo depuis la v130**, au lieu du jeu complet. Elle vérifie les fichiers et prépare l’installation. Confirmez « Installer » si Android le demande. Aucun câble USB ni recherche dans les fichiers du téléphone.

Ne désinstallez pas le jeu : la mise à jour sur place conserve la progression. La vérification peut garder son résultat jusqu’à 15 minutes ; si rien n’apparaît immédiatement, réessayez après ce délai.

## Première installation

[Télécharger Flèche & Slime v131 pour Android](https://github.com/Akeru-Games/fleche-slime-downloads/releases/download/v0.131-beta/Fleche-Slime-Android-v131.apk) — environ **1,36 Go**.

[Notes et fichiers de la v131](https://github.com/Akeru-Games/fleche-slime-downloads/releases/tag/v0.131-beta). Les fichiers `.fsdelta` sont réservés au lecteur intégré ; ils ne s’ouvrent pas manuellement. Une ancienne version sans patch compatible doit installer l’APK complète une fois, par-dessus le jeu existant.

Cette version regroupe les nouvelles arènes compactes et leurs escaliers d’arrivée, des ennemis aux comportements distincts, les dégâts spéciaux colorés et les correctifs d’interface.

Bêta distribuée par **Akeru**. Achats réels désactivés. Android ARM64 ; iOS non disponible.
