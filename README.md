# Flèche & Slime — bêta Android v130

## Vous avez déjà la v129

Connectez le téléphone au Wi-Fi, fermez complètement le jeu puis relancez-le. Le patch intégré vers la v130 fait environ **80 Mo (77 Mio)**, au lieu de retélécharger le jeu complet. Le jeu télécharge, vérifie et prépare la mise à jour, puis ouvre l’installateur Android. Confirmez l’installation si Android le demande. Aucun câble USB ni recherche dans les fichiers du téléphone.

Ne désinstallez pas le jeu : la mise à jour sur place conserve la progression.

## Première installation

[Télécharger Flèche & Slime v130 pour Android](https://github.com/Akeru-Games/fleche-slime-downloads/releases/download/v0.130-beta/Fleche-Slime-Android-v130.apk) — environ 1,35 Go.

[Notes et fichiers de la v130](https://github.com/Akeru-Games/fleche-slime-downloads/releases/tag/v0.130-beta). Les fichiers `.fsdelta` sont réservés au lecteur intégré et à la version de base exacte ; ils ne s’ouvrent pas manuellement. Une ancienne version sans patch compatible doit installer l’APK complète une fois, par-dessus le jeu existant.

Cette bêta regroupe les correctifs d’interface, le déblocage progressif des raretés, les vagues mélangées, les nouveaux obstacles et les synergies élémentaires.

Bêta distribuée par **Akeru**. Achats réels désactivés. Android ARM64 ; iOS en préparation, non disponible.
